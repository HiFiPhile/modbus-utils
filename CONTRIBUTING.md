# Contributing

Keep changes focused and include regression coverage for behavior changes.
Before submitting a change, run:

```sh
make format
make check
make test
make sanitize
```

`make test` and `make sanitize` bind an unprivileged localhost TCP port. Set
`MODBUS_TEST_PORT` when the default port `15020` is already in use.

Do not commit files generated by the bundled libmodbus `configure` script or
anything under `build/`. Update `THIRD_PARTY.md` whenever a bundled dependency
is replaced, including the upstream release, source URL, license, and checksum
or commit identifier.

The public CLI is a compatibility surface. New options should have documented
defaults, reject invalid values before I/O, and return a nonzero status on
failure. Keep transport-specific behavior behind the `tcp` or `rtu` command.
